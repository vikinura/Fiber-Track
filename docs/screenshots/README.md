# Dokumentasi Tangkapan Layar (Screenshots) Fiber Track

Folder ini memuat referensi tangkapan layar fitur-fitur utama aplikasi mobile Fiber Track:

1. `01_login_page.png`: Layar masuk multi-peran dengan validasi input dan toggle tema.
2. `02_role_home_tenant.png`: Beranda Admin Tenant (ringkasan peran, menu buat tiket, dashboard, dan kelola master).
3. `03_ticket_list.png`: Daftar tiket gangguan dengan pencarian, filter status, dan indikator SLA badge.
4. `04_ticket_form.png`: Formulir pelaporan tiket gangguan pelanggan dengan validasi area dan ODP.
5. `05_ticket_detail.png`: Detail tiket lengkap (pelanggan, SLA sisa waktu, linimasa riwayat status, dan galeri foto bukti).
6. `06_dashboard_summary.png`: Dashboard analitik rekap gangguan, kepatuhan SLA %, durasi rata-rata pengerjaan.
7. `07_dashboard_charts.png`: Visualisasi bar chart fl_chart per area dan kartu evaluasi performa mitra vendor.
8. `08_notification_page.png`: Pusat notifikasi internal dengan badge unread dan penanda telah dibaca.
9. `09_master_management.png`: Layar kelola data master area jaringan dan pelanggan dengan fitur tambah, edit, dan hapus.
10. `10_dark_mode.png`: Tampilan layar aplikasi dalam tema gelap (Material 3 Dark Mode).
